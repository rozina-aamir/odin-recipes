# Odin Recipes

The aim of this project is to create a simple recipe website in HTML by using heading, paragraph, unordered and ordered list, link, and image elements.

## Update: 10th December 2025
I've styled the site a little bit. This was mainly to explore and understand various CSS concepts (such as margin, padding, and applying rules to multiple elements), even though my inner UI Designer is screaming because the site doesn't look perfect.

You can view the [live site here](https://rozina-aamir.github.io/odin-recipes/index.html).
